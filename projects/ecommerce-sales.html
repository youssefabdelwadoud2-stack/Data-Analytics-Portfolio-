E-Commerce Retail Sales Performance Analytics

SQL Server | Excel | Power Pivot | Performance Analysis

Project Overview

This project analyzes e-commerce retail sales performance using SQL Server and Microsoft Excel.

The analysis focuses on sales performance, profitability, customers, products, quantities, discounts, and business performance indicators.

SQL Server was used to prepare and structure the analytical data before connecting the final dataset with Excel and Power Pivot.
