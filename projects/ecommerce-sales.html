E-Commerce Retail Sales Performance Analytics

SQL Server | Excel | Power Pivot | Performance Analysis

Project Overview

This project analysis focuses on E-commerce retail sales performance, profitability, customers,and products using SQL Server connected with Microsoft Excel.

SQL Server was used to prepare and structure the analytical data before connecting the final dataset with Excel and Power Pivot.

The analysis shows ($733,216) in revenue across (1,525) product and (693) customers creates (1,687) orders with (535) AVO, by around (7) quantity per order
