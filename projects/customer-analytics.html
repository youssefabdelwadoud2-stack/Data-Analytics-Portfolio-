Customer Analytics Segmentation And Retention

SQL Server | Tableau | Customer Analytics | Retention Analysis

Project Overview

This project analyzes customer behavior, segmentation, customer value, churn risk and retention using SQL Server conected with Tableau.

SQL Server was used to clean and prepare the customer data, create analytical views and build the dataset used in the Tableau dashboards.

The analysis looks at (8,000) customers who made (132,362) orders and spent a total of ($12,465,161) and overall (8.94%) churn rate.
